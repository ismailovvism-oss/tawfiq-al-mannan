## Критерий разбивки (утверждён автором: «не больше 3 предложений, можно больше если короткие»)

- Русский сектор длиннее ~400 знаков, ИЛИ больше 3 предложений при длине >350 знаков → разбить на куски ~150–350 знаков.
- Резать **только по границам предложений**, в смысловых швах (конец мысли/довода; переходы «Затем», «Поэтому», «Что касается»; начало новой цитаты).
- **Атомарны (не разрывать):** пара «строка арабского аята `۞…` + строка русского перевода вплотную под ней» (один сектор без пустой строки внутри); пары «арабский хадис + перевод»; заголовки `#…`; источник в скобках от конца цитаты; иснады `<sup>…</sup>`; стихотворные бейты; цельные записи каталогов рукописей (длиннее ~700 зн. с несколькими предложениями — можно).
- При разрыве длинной цитаты кавычки-«ёлочки» НЕ дублировать: « в первом куске, » в последнем.
- **Ни одного слова не менять, не добавлять, не удалять** — ни в русском, ни в арабском. Только вставка пустых строк. Арабский режется в той смысловой точке, где кончается соответствующий русский кусок.
- Сноски-определения `[^…]:` не трогать. Фронтматтер и `status` не трогать.
- **Сноски НЕ дробить** на отдельные определения (решение принято): читалка раскрывает их аккордеоном, парность по id важнее длины. Многоабзацность самым длинным — потом, отдельно.

Скрипт валидации (запускать из корня проекта после каждого блока):

```bash
python3 - << 'EOF'
import re, glob, os
def paras(p):
    t = open(p).read()
    m = re.match(r'^---\n.*?\n---\n+', t, re.S)
    if m: t = t[m.end():]
    ps = [x.strip() for x in re.split(r'\n\s*\n', t) if x.strip()]
    return [x for x in ps if not re.match(r'\[\^', x) and x != '---']
for f in sorted(glob.glob('source/*.md')):
    b = os.path.basename(f)
    a, r = len(paras(f)), len(paras('translation/'+b))
    if a != r: print(f'{b}: {a} ар / {r} ру РАСХОДИТСЯ')
EOF
```

Плюс проверка сохранности текста: `git diff` должен состоять ТОЛЬКО из добавленных пустых строк / разрезанных строк (никаких изменённых слов). Проверить и пары аятов: строка `۞…` в ру не должна заканчивать абзац.
