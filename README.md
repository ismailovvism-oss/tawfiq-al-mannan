# Тауфик аль-маннан — перевод

Перевод на русский арабской книги **«Тауфик аль-маннан»** — апологетического труда по акыде (защита имамов Ислама: Ибн Таймии, Ибн аль-Каййима, Ибн Абд аль-Барра, Ибн Хазма, шейха Абу Бутайна — от возводимой на них клеветы и искажения их слов).

> **Правила проекта — в [`CLAUDE.md`](CLAUDE.md).** Это управляющий файл (метод перевода, технический регламент, статусы, протокол непрерывности, интеграция с приложением «Вычитка»). Он — источник истины; README лишь вводит в курс дела.

## Структура

```
source/        арабский оригинал, 1 файл = 1 блок, без фронтматтера (только чтение)
translation/   русский перевод — единственный итоговый артефакт
variants/       справочные версии (другой ИИ, ранние редакции) — сырьё для синтеза
_meta/         стандарты: перевод (Платиновый) и шарх
CLAUDE.md      правила проекта
```

**Метка = имя файла** (`03`, `09a`). Спаривание `source/<метка>.md` ↔ `translation/<метка>.md`; варианты — `variants/<метка> <ярлык>.md` (напр. `03 chatgpt.md`).

**Длинные главы разбиты на части** буквенным суффиксом (`05a`, `05b`, `05c`) по границам аргументов — чтобы переводить и выверять единицами по ~1000–1400 слов. Все части одной главы — единый смысловой блок (см. «Протокол непрерывности» в `CLAUDE.md`).

## Как работать

Книга переводится в приложении **«Вычитка»** — однофайловом веб-инструменте сверки, который открывает эту папку и показывает рядом оригинал, перевод и варианты. Логика и требования к формату — в разделе «Рабочий инструмент — Вычитка» в `CLAUDE.md`. Приложение хранится отдельно (репозиторий `translator panel`); чтобы пользоваться им с любого устройства, можно положить `vychitka.html` в корень этого репозитория или открывать хостинг-версию и указывать ей на склонированную папку.

Перевод идёт в два прогона: **прогон 1 (смысл)** по Платиновому стандарту (`_meta/TRANSLATION_STANDARD.md`), затем сверка автора с арабским, затем **прогон 2 (форма)** — технический регламент из `CLAUDE.md`.
